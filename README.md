# NOIRÉ — Luxury Fashion Store

## Project Overview
NOIRÉ is a luxury fashion e-commerce website created as a school project. It showcases fashion products through a modern, elegant interface with interactive features and 3D product displays.

## Project Topic
Build a Simple Webpage with AI, Git & GitHub.

## Technologies Used
- HTML5 — webpage structure
- CSS3 — styling, responsive layouts, and animations
- JavaScript — interactive website functionality
- Git — version control
- GitHub — online repository and project hosting
- AI assistance — planning, coding support, debugging, and improvements

## Features
- Luxury-inspired dark design
- Fashion product listings and product details
- Interactive 3D product models
- Product images and categories
- Animated visual elements
- Responsive layout for different screen sizes
- **Interactive 3D Product Viewer:** Explore selected watches using interactive 3D models.
- **Light and Dark Mode:** Switch between light and dark themes using a sun/moon toggle.
- **Saved Theme Preference:** The selected theme is remembered when navigating between the homepage and product detail pages.
- **Responsive Product Details:** View product images, descriptions, prices in Nigerian Naira (₦), and interactive models where available.

## AI Tool Used
ChatGPT.

## How AI Helped
ChatGPT helped with planning the website, writing and improving HTML, CSS, and JavaScript, troubleshooting product images and 3D model displays, refining the product page, and guiding Git and GitHub version-control steps.

## How to Run the Project
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Ensure the `assets` folder and other project files remain in their original locations so images and 3D models can load correctly.
